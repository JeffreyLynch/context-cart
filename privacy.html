Context Cart Privacy Policy

Last updated: June 11, 2026

Context Cart is a local-first browser extension. It has no backend service, no accounts, no analytics, no telemetry, and it makes no network requests of its own. This policy explains exactly what data the extension handles, where it lives, and the only ways it ever leaves your browser.

What the extension stores, and where

Everything Context Cart saves is stored locally in your browser using chrome.storage.local:

  • Snippets — text you select and capture, plus the page title, page URL, and a timestamp for each snippet.
  • Page links — URLs and titles of pages or links you add via right-click.
  • Manual notes you type into the side panel.
  • Carts — the named groups you organize snippets into.
  • Saved prompts and your settings.

This data never leaves your device unless you take one of the explicit actions listed below. The developer has no access to it. There is no server copy.

How data can leave the extension (always user-initiated)

Data leaves Context Cart only when you explicitly:

  1. Copy a composed prompt or Markdown export — the text is written to your system clipboard. The extension only writes to the clipboard; it never reads it.
  2. Open a draft in ChatGPT — the composed prompt is sent to chatgpt.com. When the prompt is small enough, this works by opening a ChatGPT URL that contains your prompt as a query parameter (chatgpt.com/?q=...). Note: like any URL you visit, that URL — including the prompt text — appears in your browser history. If you are signed in to ChatGPT, the prompt is prefilled for you to review and send; if you are signed out, ChatGPT may submit it immediately as a new chat. Longer prompts are copied to your clipboard instead of being placed in a URL.
  3. Send to ChatGPT with autosubmit or "current conversation" mode (both off by default) — the extension fills the ChatGPT message box on chatgpt.com with your composed prompt and, if autosubmit is on, submits it. This requires an optional permission (see below). The extension never reads ChatGPT's responses or anything else on the page.
  4. Send to Claude — the composed prompt is copied to your clipboard and a Claude draft is opened. When the prompt is small enough, claude.ai opens with the prompt prefilled via a URL parameter (claude.ai/new?q=...) — like any URL you visit, it appears in your browser history; you review and send. If you enable the Claude Desktop option, the prompt is passed to the Claude Desktop app via its documented claude:// link instead (also prefill-only). Context Cart never injects scripts into claude.ai.

What you send to ChatGPT or Claude is then governed by those services' own privacy policies: OpenAI Privacy Policy and Anthropic Privacy Policy.

What the extension never does

  • No analytics, telemetry, or usage tracking of any kind.
  • No network requests initiated by the extension itself.
  • No reading of pages in the background — capture happens only when you right-click and choose a Context Cart menu item, or press the capture shortcut (Alt+Shift+A), and only on the page you're viewing at that moment.
  • No reading of AI chat responses or any other page content beyond your selection.
  • No selling, sharing, or transmitting of user data to the developer or any third party.

Permissions

  • contextMenus — adds the right-click capture actions.
  • storage — stores carts, snippets, prompts, and settings locally.
  • sidePanel — displays the Context Cart side panel.
  • activeTab — grants temporary access to the current tab only when you invoke a capture action, so the selection, page title, and URL can be read.
  • scripting — used for exactly two things, both user-initiated: reading your text selection when you press the capture shortcut, and filling the ChatGPT message box when you use the optional send features.
  • Optional https://chatgpt.com/* host access — requested only if you enable autosubmit or current-conversation mode in Settings. Turning both options off removes this permission automatically. Without it, the extension never touches chatgpt.com pages.

Retention and deletion

Your data stays on your device until you delete it. Removing snippets or carts in the side panel deletes them from local storage; uninstalling the extension removes all stored data. There is nothing to delete on any server, because nothing is ever uploaded.
